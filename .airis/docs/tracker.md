# Tracker - Global Task Registry

> **Template:** Use `_setup/templates/4-tracker.template.md` to create this document
> **Prompt:** Use `_setup/prompts/5-tracker.prompt.md` for AI assistance

This file will contain all development tasks derived from the strategy documents.

## How to Create

1. First complete: design.md and scope.md (features in §4)
2. Use the prompt: Load `_setup/prompts/5-tracker.prompt.md` and ask Claude to generate Tracker.md

## What Goes Here

- Complete task registry with IDs (T-001, T-002, etc.)
- Task status (⚪ Not Started, 🟡 In Progress, ✅ Complete, ⏸️ Blocked)
- Dependencies between tasks
- Effort estimates and actual time
- Progress metrics
- Updated after each session

## Task Status Legend

- ⚪ Not Started - Ready to begin
- 🟡 In Progress - Currently being worked
- ✅ Complete - Finished and validated
- ⏸️ Blocked - Cannot start (dependency)
- 🚫 Cancelled - No longer needed
